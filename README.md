# Power-BI-Data-World-Salary-Analysis-Portfolio
This project analyzes the salaries of various data roles and job titles

## Features
- Top data jobs based on salary and pay
- Data roles with the most workers
- Distribution of various data roles across different companies
- Distribution of various currencies among workers

## Tools used
- Power BI
